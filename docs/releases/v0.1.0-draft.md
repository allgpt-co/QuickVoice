# QuickVoice v0.1.0

> **Status: draft — not released.** No `v0.1.0` tag or GitHub release is created by this document. Content can change until the [release checklist](./release-checklist.md) is complete and the repository lead approves publication.

## Release Intent

v0.1.0 is intended to be the first versioned source snapshot for developers evaluating self-hosted AI phone-agent infrastructure. It should establish a reproducible baseline and honest operating boundaries, not claim production stability.

## Candidate Contents

The current source tree includes:

- A Next.js customer console and public website.
- An Express/TypeScript API with Postgres, Prisma, Redis/BullMQ, authentication, organizations, agent configuration, call records, campaigns, billing paths, and provider integrations.
- A Python AI API and LiveKit worker path with configurable speech/model providers, knowledge retrieval, and controlled tool execution.
- Twilio and Telnyx telephony integration paths.
- Local orchestration for environment templates, dependencies, Postgres, Redis, migrations, and services.
- Tests, dependency auditing, backend image builds, deployment workflows, and security guidance.
- Governance, support, contribution, roadmap, changelog, issue-form, and release-readiness documentation.

This list describes source areas present in the candidate. It does not mean every integration works from placeholder configuration or that every path has completed provider-connected staging verification.

## Install For Evaluation

Required host tools:

- Linux with Bash `>=4` (including WSL2)
- Node.js `^20.19 || ^22.13 || >=24` with Corepack
- `pnpm@9.0.0`
- Python 3; Python 3.12 matches CI and the AI runtime image
- Docker with Compose v2
- Go Task

macOS can use the Linux-oriented scripts when a modern Bash appears first on `PATH`. Native Windows PowerShell and Command Prompt are not supported for the one-command flow.

```sh
task doctor
task up:dev
```

The task creates ignored local env files from tracked templates, installs dependencies, starts local Postgres and Redis, applies Prisma migrations, and starts the local services.

## Known Limitations

- **Pre-stable compatibility:** APIs, schemas, configuration, and deployment assumptions may change before 1.0. No backwards-compatibility guarantee is made by this draft.
- **No zero-setup hosted service:** the repository is a self-hostable codebase. Operators are responsible for infrastructure, domains, TLS, secrets, backups, monitoring, scaling, upgrades, and incident response.
- **Placeholder configuration:** development templates contain placeholders. Service startup does not prove that an external integration is configured.
- **Live calls need providers:** carrier-connected calls require LiveKit, Twilio or Telnyx, speech/model providers, authorized phone numbers, and the operator's own accounts, permissions, budget, and configuration.
- **Cloud inference by default:** the documented default voice path uses commercial provider services. This release does not promise a local-LLM or fully offline voice stack.
- **Other provider-backed flows:** OAuth, Stripe billing, external email delivery, S3-compatible storage, Pinecone retrieval, and production webhooks require separately configured services.
- **Operating-system path:** root orchestration is Bash-based. Windows users should use WSL2; macOS needs Bash `>=4`.
- **Provider coverage varies:** a code path or unit test is not evidence that every account, region, carrier, model, voice, quota, webhook, or failure mode was tested for this candidate.
- **Compliance is deployment-specific:** the repository is not a HIPAA, SOC 2, ISO 27001, PCI, GDPR, or CCPA certification. Operators must evaluate law, contracts, consent, recording disclosures, retention, access, subprocessors, and audit controls.
- **No guaranteed support or SLA:** community support is best effort under [SUPPORT.md](../../SUPPORT.md).
- **Source release only unless stated otherwise:** do not assume public container images, hosted endpoints, package-registry artifacts, or managed upgrades are included unless the final GitHub release explicitly links them.
